## 🏛️ Featured Engineering Architectures

### 💳 1. Production GenAI Financial Analytics Platform (2024 – Present)
- **Problem**: Non-technical financial analysts required instant SQL analytics across millions of payment processing records.
- **Solution**: Engineered a schema-aware RAG system using vector schema retrieval, semantic query compilation, AST SQL validation, multi-tenant isolation, and Server-Sent Events (SSE) token streaming.
- **Key Metrics**: 99.1% SQL generation accuracy, 0.00% multi-tenant leakage, 110ms TTFT streaming.

### 🎙️ 2. Speech & Conversation Intelligence Platform (2023)
- **Problem**: Inbound customer calls lacked structured QA insights, sentiment categorization, and objection intelligence.
- **Solution**: Implemented an asynchronous pipeline leveraging Faster-Whisper for STT transcription, transformer-based NLP for objection and intent extraction, and Redis queue pools for decoupled ingestion.
- **Key Metrics**: 0.18x Real-Time Factor (RTF), 94.6% sentiment classification precision.

### 📑 3. AI-Powered Insurance Quotation Engine (2020 – 2022)
- **Problem**: Manual extraction and actuarial rating of insurance submissions created multi-day backlogs.
- **Solution**: Automated policy document parsing and built a high-concurrency Redis task queue feeding an actuarial rating engine.
- **Key Metrics**: 150+ concurrent requests handled, 85% reduction in manual processing time, 99.9% delivery reliability.

### 📊 4. Enterprise MLOps Lifecycle & Drift Detection (2018 – 2020)
- **Problem**: Model drift and lack of reproducibility in behavioral churn prediction models.
- **Solution**: Developed an end-to-end MLOps pipeline featuring PySpark preprocessing, MLflow experiment tracking, model registry governance, and Kolmogorov-Smirnov / PSI feature drift monitoring.
- **Key Metrics**: Sub-15ms P95 inference latency, 0.892 ROC-AUC baseline.
